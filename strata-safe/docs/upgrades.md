## Trial protocol

- `inference-speed` / `fit-bigger` run on the cached 27B `qwen3.8-27b-uncensored:latest`
  GGUF through Ollama's bundled `llama-server`, 50 real R2 ingest prompts, greedy.
- `fine-tune-efficiency` runs a 6-step NF4 QLoRA loop on the cached 9B base
  `empero-ai/Qwen3.8-9B-Distill` and reports step time and `torch.cuda.max_memory_allocated`.
- `data-tools` runs the 9B on the hard sales-brain transcript extraction task
  (7 deal fields) and reports field-F1, schema validity and latency.
